# Connect PHP vs REST comparisons

This directory contains machine-readable, per-object comparisons between Oracle B2C Service Connect PHP (RNCPHP) and Connect REST.

The goal is not to assume that a shared CCOM concept means identical API behaviour. Each comparison should identify equivalence, representation differences, binding-specific fields/actions and anything that still needs verification.

See [`../guides/connect-php-vs-rest.md`](../guides/connect-php-vs-rest.md) for the status model and comparison methodology.
