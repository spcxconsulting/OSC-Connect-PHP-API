# Copyright and source policy

This project is designed to be useful without republishing Oracle's documentation.

## We include

- Oracle product and API identifiers needed for interoperability;
- object/class/property names;
- links to Oracle's authoritative documentation;
- independently written explanations;
- independently written example code;
- SPCX implementation notes and troubleshooting guidance.

## We do not include

- copied Oracle documentation pages;
- large copied portions of Oracle prose;
- wholesale copies of Oracle sample code;
- Oracle images, stylesheets or documentation assets.

When an example is inspired by a documented API capability, the implementation is rewritten from scratch with different sample data and SPCX commentary.

Oracle remains the authoritative source for supported versions, object contracts, field behaviour and product licensing.
