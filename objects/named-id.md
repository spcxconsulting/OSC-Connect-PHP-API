# NamedID

**CCOM resource:** `named-ids`

## SPCX summary

A compact identifier-plus-name helper commonly used when another object refers to a menu or reference value.

## Connect PHP status

Helper/reference type catalogued. Its exact concrete helper classes and writable behaviour can vary by context and Connect PHP version, so examples will be added only after version verification.
